# Coleta de Dados Meteorológicos - INPE 

Repositório voltado para a automação e download de dados meteorológicos públicos disponibilizados pelo **INPE**. 

---

## 📌 Objetivo

Este projeto busca centralizar e automatizar a extração de dados públicos do INPE, garantindo um pipeline simples e reprodutível para que o grupo de pesquisa possa utilizar essas informações em análises e modelos preditivos.

---

## 🛠️ Tecnologias Utilizadas

* **Python 3.x**
* **Requests** (Download de arquivos)
* **Pandas / Numpy* (Manipulação e leitura dos dados)
